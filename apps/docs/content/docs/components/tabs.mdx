# Tabs

The `Tabs` component provides a way to organize content into multiple sections that can be accessed through tab triggers. It supports multiple variants, orientations, and is fully accessible with keyboard navigation and ARIA attributes.

## Installation

Ensure that you have the @zyxui library installed in your project:
<Example>
```bash
pnpm add @zyxui/tabs
```
</Example>

If you haven't installed and setup @zyxui before, please follow the [`installation guide`](/docs/installation)

## Basic Tabs

The most basic usage of the Tabs component consists of a Tabs container, TabsList for the tab triggers, TabsTrigger for individual tabs, and TabsContent for the content panels.

<Example>
  <Preview className='flex flex-wrap justify-center items-center'>

## Controlled Usage

For advanced use cases where you need to control the tab state programmatically, you can use the `value` and `onValueChange` props instead of `defaultValue`.

```jsx showLineNumbers
import { useState } from 'react';
import { Tabs, TabsList, TabsTrigger, TabsContent } from '@zyxui/tabs';

export const ControlledTabsExample = () => {
  const [activeTab, setActiveTab] = useState('step1');

  return (
    <div className="space-y-4">
      <div className="flex gap-2">
        <button onClick={() => setActiveTab('step1')}>Go to Step 1</button>
        <button onClick={() => setActiveTab('step2')}>Go to Step 2</button>
        <button onClick={() => setActiveTab('step3')}>Go to Step 3</button>
      </div>

      <Tabs value={activeTab} onValueChange={setActiveTab}>
        <TabsList className="grid w-full grid-cols-3">
          <TabsTrigger value="step1">Step 1</TabsTrigger>
          <TabsTrigger value="step2">Step 2</TabsTrigger>
          <TabsTrigger value="step3">Step 3</TabsTrigger>
        </TabsList>

        <TabsContent value="step1">
          <div className="p-6 text-center">
            <h3 className="font-semibold mb-2">Step 1: Information</h3>
            <p className="text-sm text-muted-foreground">
              Current tab: {activeTab}
            </p>
          </div>
        </TabsContent>

        <TabsContent value="step2">
          <div className="p-6 text-center">
            <h3 className="font-semibold mb-2">Step 2: Confirmation</h3>
            <p className="text-sm text-muted-foreground">
              Current tab: {activeTab}
            </p>
          </div>
        </TabsContent>

        <TabsContent value="step3">
          <div className="p-6 text-center">
            <h3 className="font-semibold mb-2">Step 3: Complete</h3>
            <p className="text-sm text-muted-foreground">
              Current tab: {activeTab}
            </p>
          </div>
        </TabsContent>
      </Tabs>
    </div>
  )
}
```

## API Reference

### Tabs

The root tabs component that provides context to all child components.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | The controlled value of the tabs |
| `defaultValue` | `string` | - | The default value for uncontrolled usage |
| `onValueChange` | `(value: string) => void` | - | Callback fired when the tab changes |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | The orientation of the tabs |
| `variant` | `'default' \| 'underline' \| 'pills'` | `'default'` | The visual variant of the tabs |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | The size of the tab triggers |
| `className` | `string` | - | Additional CSS classes |

### TabsList

The container for tab triggers.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | - | Additional CSS classes |

### TabsTrigger

Individual tab trigger button.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | **Required.** The value that identifies this tab |
| `className` | `string` | - | Additional CSS classes |
| `disabled` | `boolean` | `false` | Whether the tab is disabled |

### TabsContent

The content panel for each tab.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | **Required.** The value that identifies this content |
| `className` | `string` | - | Additional CSS classes |

## Accessibility

The Tabs component follows WAI-ARIA guidelines for accessibility:

- **Keyboard Navigation**: Arrow keys navigate between tabs, Home/End keys jump to first/last tab
- **Focus Management**: Proper focus indicators and management
- **ARIA Attributes**: Uses `role="tablist"`, `role="tab"`, and `role="tabpanel"`
- **Screen Reader Support**: Proper labeling and association between tabs and content
- **State Communication**: Active/inactive states are communicated to assistive technologies

### Keyboard Shortcuts

- `Arrow Keys`: Navigate between tabs
- `Home`: Move to first tab
- `End`: Move to last tab
- `Space/Enter`: Activate focused tab

## Best Practices

1. **Use descriptive tab labels** that clearly indicate the content
2. **Limit the number of tabs** to avoid overwhelming users (5-7 tabs maximum recommended)
3. **Consider vertical orientation** for side navigation patterns
4. **Provide loading states** for content that needs to be fetched
5. **Use controlled tabs** when you need to programmatically change the active tab
6. **Ensure content is accessible** in all tab panels

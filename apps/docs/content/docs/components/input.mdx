# Input

The `Input` component is a comprehensive form control that provides users with a text input field. It includes support for various states, validation, accessibility features, and customization options. Built with React Aria for maximum accessibility compliance.

## Installation

Ensure that you have the @zyxui library installed in your project:
<Example>
```bash
npm install @zyxui/input
```
</Example>

If you haven't installed and setup @zyxui before, please follow the [`installation guide`](/docs/installation)

## Basic Input

To create a basic input, simply use the Input component with a placeholder. It will inherit the default styling.

<Example>
  <Preview className='flex flex-wrap flex-row gap-10 justify-center items-center'>
    <Input placeholder="Enter text here" />
  </Preview>

  ```jsx showLineNumbers
  import Input from '@zyxui/input';

  export const BasicInputExample = () => {
    return (
      <Input placeholder="Enter text here" />
    )
  }
  ```
</Example>

The `Input` component is <ins>**highly customizable**</ins>, allowing you to fine-tune its appearance and behavior to align with your project's unique requirements. Explore the following customization options:

Add a label to your input for better accessibility and user experience.


## API Reference

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Label text for the input |
| `placeholder` | `string` | - | Placeholder text |
| `variant` | `'default' \| 'filled' \| 'underlined' \| 'bordered'` | `'default'` | Input style variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Input size |
| `state` | `'default' \| 'error' \| 'success' \| 'warning'` | `'default'` | Input state for validation |
| `radius` | `'none' \| 'sm' \| 'md' \| 'lg' \| 'full'` | `'md'` | Border radius |
| `startContent` | `ReactNode` | - | Content to display at the start of the input |
| `endContent` | `ReactNode` | - | Content to display at the end of the input |
| `helperText` | `string` | - | Helper text below the input |
| `errorMessage` | `string` | - | Error message (overrides helperText) |
| `required` | `boolean` | `false` | Whether the field is required |
| `disabled` | `boolean` | `false` | Whether the input is disabled |
| `clearable` | `boolean` | `false` | Whether to show a clear button |
| `onClear` | `() => void` | - | Callback when clear button is clicked |
| `className` | `string` | - | Additional CSS classes for the input |
| `containerClassName` | `string` | - | Additional CSS classes for the container |
| `labelClassName` | `string` | - | Additional CSS classes for the label |

The Input component also accepts all standard HTML input attributes through React Aria's `AriaTextFieldOptions`.

## Accessibility

The Input component is built with accessibility in mind:

- ✅ **Keyboard Navigation**: Full keyboard support for all interactions
- ✅ **Screen Reader Support**: Proper ARIA labels and descriptions
- ✅ **Focus Management**: Clear focus indicators and logical tab order
- ✅ **Error Handling**: Accessible error messages and validation states
- ✅ **Required Fields**: Clear indication of required fields

## Best Practices

1. **Always provide labels** for better accessibility
2. **Use appropriate input types** (email, password, etc.)
3. **Provide helpful error messages** that guide users to fix issues
4. **Use helper text** to clarify input expectations
5. **Group related inputs** logically in forms
6. **Test with keyboard navigation** and screen readers

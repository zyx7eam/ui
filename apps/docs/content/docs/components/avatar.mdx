# Avatar

The `Avatar` component is a versatile element for displaying user profile pictures, initials, or icons. Perfect for user interfaces, comment sections, and user lists.

## Installation

Ensure that you have the @zyxui library installed in your project:
<Example>
```bash
pnpm add @zyxui/avatar
```
</Example>

If you haven't installed and setup @zyxui before, please follow the [`installation guide`](/docs/installation)

## Basic Avatar

The most basic usage of the Avatar component with different content types.

<Example>
  <Preview className='flex flex-wrap gap-4 items-center'>
    <Avatar src="https://i.pravatar.cc/150?u=a042581f4e29026704d" alt="User 1" />
    <Avatar fallback="JD" color="primary" />
    <Avatar icon={<User />} color="secondary" />
    <Avatar src="/invalid.jpg" fallback={<Camera />} color="danger" />
  </Preview>

  ```jsx showLineNumbers
  import { Avatar } from '@zyxui/avatar';
  import { User, Camera } from 'lucide-react';

  export const BasicAvatarExample = () => {
    return (
      <>
        <Avatar src="https://i.pravatar.cc/150?u=a042581f4e29026704d" alt="User 1" />
        <Avatar fallback="JD" color="primary" />
        <Avatar icon={<User />} color="secondary" />
        <Avatar src="/invalid.jpg" fallback={<Camera />} color="danger" />
      </>
    )
  }
  ```
</Example>

## API Reference

### Avatar

The Avatar component extends `HTMLDivElement` and includes the following props:

| Prop             | Type                                                            | Default        | Description                                                                 |
|------------------|-----------------------------------------------------------------|----------------|-----------------------------------------------------------------------------|
| `src`            | `string`                                                        | -              | The URL of the image to display                                            |
| `alt`            | `string`                                                        | `''`          | Alt text for the image, also used for initial generation if no fallback    |
| `icon`           | `React.ReactNode`                                               | -              | A custom icon to display as a fallback if `src` is invalid                 |
| `fallback`       | `React.ReactNode`                                               | -              | Custom content to display if `src` is invalid. Takes precedence over `icon` |
| `size`           | `'sm' \| 'md' \| 'lg' \| 'xl'`                                     | `'md'`         | The size of the avatar                                                     |
| `shape`          | `'circle' \| 'square'`                                          | `'circle'`     | The shape of the avatar                                                    |
| `color`          | `'default' \| 'primary' \| 'secondary' \| 'success' \| 'warning' \| 'danger'` | `'default'`    | The background color when displaying fallback content        |
| `bordered`       | `boolean`                                                       | `false`        | If `true`, adds a border to the avatar                                   |
| `disabled`       | `boolean`                                                       | `false`        | If `true`, applies a disabled style                             |
| `status`         | `'online' \| 'offline' \| 'away' \| 'busy'`                           | -              | Shows a status indicator                                |
| `statusPosition` | `'top-right' \| 'bottom-right' \| 'top-left' \| 'bottom-left'`         | `'bottom-right'` | Position of the status indicator                                                 |

### Accessibility

- Always provide meaningful `alt` text for avatar images
- Use `aria-label` when the avatar represents a user or entity
- Ensure interactive avatars are keyboard accessible and have appropriate ARIA attributes
- Consider using `aria-live` regions for status changes

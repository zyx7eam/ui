# Card

The `Card` component is a flexible container that groups related content and actions. It provides a clean, organized way to display information with support for headers, body content, and footer actions. Perfect for creating product cards, user profiles, articles, and more.

## Installation

Ensure that you have the @zyxui library installed in your project:
<Example>
```bash
npm install @zyxui/card
```
</Example>

If you haven't installed and setup @zyxui before, please follow the [`installation guide`](/docs/installation)

## Basic Card

To create a basic card, simply use the Card component with some content. It will inherit the default elevated styling.

<Example>
  <Preview className='flex flex-wrap justify-center items-center'>
    <Card className="w-80">
      <CardBody>
        <p>This is a basic card with some content inside.</p>
      </CardBody>
    </Card>
  </Preview>

  ```jsx showLineNumbers
  import { Card, CardBody } from '@zyxui/card';

  export const BasicCardExample = () => {
    return (
      <Card className="w-80">
        <CardBody>
          <p>This is a basic card with some content inside.</p>
        </CardBody>
      </Card>
    )
  }
  ```
</Example>

## Card Structure

The Card component consists of multiple sub-components that work together to create a structured layout.

<Example>
  <Preview className='flex flex-wrap justify-center items-center'>

      <CardHeader>

### Clickable Cards

Cards can be made clickable by adding an `onClick` handler, which automatically makes them hoverable.

<Example>
  <Preview className='flex flex-wrap gap-6 justify-center items-center'>
    <Card onClick={() => alert('Card clicked!')} className="w-80">
      <CardHeader>
        <CardTitle>Clickable Card</CardTitle>
        <CardDescription>
          Click this card to trigger an action.
        </CardDescription>
      </CardHeader>
      <CardBody>
        <p>This entire card is clickable and will show an alert when clicked.</p>
      </CardBody>
    </Card>
  </Preview>

  ```jsx showLineNumbers
  import { Card, CardHeader, CardBody, CardTitle, CardDescription } from '@zyxui/card';

  export const ClickableCardExample = () => {
    return (
      <Card onClick={() => alert('Card clicked!')} className="w-80">
        <CardHeader>
          <CardTitle>Clickable Card</CardTitle>
          <CardDescription>
            Click this card to trigger an action.
          </CardDescription>
        </CardHeader>
        <CardBody>
          <p>This entire card is clickable and will show an alert when clicked.</p>
        </CardBody>
      </Card>
    )
  }
  ```
</Example>

## API Reference

### Card Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'elevated' \| 'outlined' \| 'filled' \| 'ghost'` | `'elevated'` | Card style variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Card padding size |
| `radius` | `'none' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Border radius |
| `hoverable` | `boolean` | `false` | Whether the card should have hover effects |
| `blurred` | `boolean` | `false` | Whether to apply glass effect |
| `onClick` | `() => void` | - | Click handler (automatically makes card hoverable) |
| `className` | `string` | - | Additional CSS classes |
| `children` | `ReactNode` | - | Card content |

### Sub-components

- **CardHeader**: Container for card header content
- **CardBody**: Container for main card content
- **CardFooter**: Container for card footer actions
- **CardTitle**: Styled heading for card titles
- **CardDescription**: Styled text for card descriptions

All sub-components accept standard HTML attributes and a `className` prop for customization.

## Accessibility

The Card component is built with accessibility in mind:

- ✅ **Semantic HTML**: Uses appropriate HTML elements for structure
- ✅ **Keyboard Navigation**: Clickable cards are keyboard accessible
- ✅ **Focus Management**: Clear focus indicators for interactive cards
- ✅ **Screen Reader Support**: Proper content structure for screen readers

## Best Practices

1. **Use consistent card layouts** across your application
2. **Group related content** logically within cards
3. **Provide clear visual hierarchy** with titles and descriptions
4. **Make interactive intent clear** with hover states and cursor changes
5. **Keep content concise** and scannable
6. **Use appropriate spacing** between card elements
7. **Test hover and click interactions** across devices

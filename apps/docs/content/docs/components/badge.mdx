# Badge

The `Badge` component is a versatile element used to highlight status, display counts, or mark content with short labels. Perfect for notifications, status indicators, and labeling items.

## Installation

Ensure that you have the @zyxui library installed in your project:
<Example>
```bash
pnpm add @zyxui/badge
```
</Example>

If you haven't installed and setup @zyxui before, please follow the [`installation guide`](/docs/installation)

## Basic Badge

The most basic usage of the Badge component is to display a simple label or count.

<Example>
  <Preview className='flex flex-wrap gap-4 items-center'>
    <Badge content="New" />
    <Badge content={5} color="primary" />
    <Badge content="Beta" variant="outline" />
    <Badge dot color="success" />
  </Preview>

  ```jsx showLineNumbers
  import { Badge } from '@zyxui/badge';

  export const BasicBadgeExample = () => {
    return (
      <>
        <Badge content="New" />
        <Badge content={5} color="primary" />
        <Badge content="Beta" variant="outline" />
        <Badge dot color="success" />
      </>
    )
  }
  ```
</Example>

## API Reference

### Badge

The Badge component extends `HTMLSpanElement` and includes the following props:

| Prop        | Type                                                                              | Default     | Description                                                                                                |
|-------------|-----------------------------------------------------------------------------------|-------------|------------------------------------------------------------------------------------------------------------|
| `content`   | `React.ReactNode`                                                                 | -           | The content to display inside the badge                                            |
| `max`       | `number`                                                                          | `99`        | Maximum value to display. If `content` is a number and exceeds `max`, it will show `{max}+`                |
| `showZero`  | `boolean`                                                                         | `false`     | If `true`, the badge will be visible when `content` is `0`                    |
| `dot`       | `boolean`                                                                         | `false`     | If `true`, renders the badge as a small dot, ignoring `content`      |
| `variant`   | `'solid' \| 'outline' \| 'ghost' \| 'dot'`                                           | `'solid'`   | The visual style of the badge                                                                             |
| `color`     | `'default' \| 'primary' \| 'secondary' \| 'success' \| 'warning' \| 'danger' \| 'info'` | `'default'` | The color scheme of the badge                                                                               |
| `size`      | `'sm' \| 'md' \| 'lg'`                                                                | `'md'`      | The size of the badge                                                    |
| `shape`     | `'rounded' \| 'pill'`                                                              | `'pill'`    | The shape of the badge                                                                                    |
| `invisible` | `boolean`                                                                         | `false`     | If `true`, the badge is not rendered                                                                      |

### Accessibility

- For decorative badges (like dots), use `aria-hidden="true"` to hide them from screen readers
- For informative badges (like counts), ensure the content is meaningful and accessible
- When wrapping interactive elements, make sure the badge content is properly announced with the interactive element
